Private Party Markers est un plugin Dalamud qui affiche de petits points privés au sol sous votre personnage et les équipiers sélectionnés.

- Les repères sont affichés uniquement sur votre client.
- Le plugin ne place ni ne modifie les signes de cible ou les repères de terrain du jeu.
- Il n'automatise ni le ciblage ni les actions et n'envoie aucune identité ni position de joueur.
- Chaque équipier sélectionné peut utiliser l'une des 16 couleurs prédéfinies.
- L'affichage s'arrête lorsqu'un membre quitte l'équipe, n'est plus chargé ou ne peut pas être projeté à l'écran.
- Le chinois simplifié, le chinois traditionnel, l'anglais et le japonais sont pris en charge.

## Installation

1. Installez et lancez XIVLauncher avec Dalamud activé.
2. Ouvrez **Dalamud Settings → Experimental**.
3. Ajoutez l'URL de dépôt personnalisé suivante :

   ```text
   https://raw.githubusercontent.com/chefiffer/dalamud-plugins/main/repo.json
   ```

4. Ouvrez l'installateur de plugins, recherchez **Private Party Markers**, puis sélectionnez **Install**.
5. Utilisez `/partydots` dans le chat du jeu pour ouvrir la fenêtre de configuration.

Les membres sélectionnés sont enregistrés uniquement dans la configuration locale du plugin, sous la forme `name@home-world-ID`. Vérifiez les fichiers de configuration avant de les partager.
