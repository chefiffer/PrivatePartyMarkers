# Private Party Markers

Private Party Markers — плагин Dalamud, который рисует небольшие приватные точки на земле под вами и выбранными участниками группы.

- Метки отображаются только на вашем клиенте.
- Плагин не устанавливает и не изменяет игровые метки целей или поля.
- Он не автоматизирует выбор целей или действия и не отправляет личность или позиции игроков.
- Для каждого выбранного участника можно назначить один из 16 готовых цветов.
- Отображение прекращается, если участник покинул группу, больше не загружен или не может быть спроецирован на экран.
- Поддерживаются упрощённый и традиционный китайский, английский и японский языки.

## Установка

1. Установите и запустите XIVLauncher с включённым Dalamud.
2. Откройте **Dalamud Settings → Experimental**.
3. Добавьте следующий адрес пользовательского репозитория:

   ```text
   https://raw.githubusercontent.com/chefiffer/dalamud-plugins/main/repo.json
   ```

4. Откройте установщик плагинов, найдите **Private Party Markers** и выберите **Install**.
5. Введите `/partydots` в игровом чате, чтобы открыть окно настроек.

Выбранные участники сохраняются только в локальной конфигурации плагина в виде `name@home-world-ID`. Проверяйте конфигурационные файлы перед публикацией.
