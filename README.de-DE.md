# Private Party Markers

Private Party Markers ist ein Dalamud-Plugin, das kleine, private Bodenpunkte unter dir und ausgewählten Gruppenmitgliedern zeichnet.

- Markierungen werden nur auf deinem Client dargestellt.
- Ziel- oder Feldmarkierungen im Spiel werden weder gesetzt noch verändert.
- Das Plugin automatisiert weder Zielauswahl noch Aktionen und lädt keine Spieleridentitäten oder Positionen hoch.
- Für jedes ausgewählte Mitglied kann eine von 16 voreingestellten Farben verwendet werden.
- Die Darstellung endet, wenn ein Mitglied die Gruppe verlässt, nicht mehr geladen ist oder nicht auf den Bildschirm projiziert werden kann.
- Vereinfachtes Chinesisch, traditionelles Chinesisch, Englisch und Japanisch werden unterstützt.

## Installation

1. Installiere und starte XIVLauncher mit aktiviertem Dalamud.
2. Öffne **Dalamud Settings → Experimental**.
3. Füge diese benutzerdefinierte Repository-URL hinzu:

   ```text
   https://raw.githubusercontent.com/chefiffer/dalamud-plugins/main/repo.json
   ```

4. Öffne den Plugin-Installer, suche nach **Private Party Markers** und wähle **Install**.
5. Gib `/partydots` im Spielchat ein, um das Einstellungsfenster zu öffnen.

Ausgewählte Mitglieder werden ausschließlich in der lokalen Plugin-Konfiguration als `name@home-world-ID` gespeichert. Prüfe Konfigurationsdateien, bevor du sie weitergibst.
