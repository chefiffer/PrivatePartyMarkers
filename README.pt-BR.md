# Private Party Markers

Private Party Markers é um plugin do Dalamud que desenha pequenos pontos privados no chão, sob você e os membros selecionados do grupo.

- Os marcadores são renderizados somente no seu cliente.
- O plugin não define nem altera marcadores de alvo ou de campo do jogo.
- Ele não automatiza a seleção de alvos nem ações e não envia identidades ou posições de jogadores.
- Cada membro selecionado pode usar uma das 16 cores predefinidas.
- Os marcadores deixam de ser desenhados quando um membro sai do grupo, deixa de estar carregado ou não pode ser projetado na tela.
- Há suporte para chinês simplificado, chinês tradicional, inglês e japonês.

## Instalação

1. Instale e inicie o XIVLauncher com o Dalamud ativado.
2. Abra **Dalamud Settings → Experimental**.
3. Adicione a URL abaixo como repositório personalizado:

   ```text
   https://raw.githubusercontent.com/chefiffer/dalamud-plugins/main/repo.json
   ```

4. Abra o instalador de plugins, procure **Private Party Markers** e selecione **Install**.
5. Digite `/partydots` no chat do jogo para abrir a janela de configurações.

Os membros selecionados são armazenados somente na configuração local do plugin, no formato `name@home-world-ID`. Revise os arquivos de configuração antes de compartilhá-los.
