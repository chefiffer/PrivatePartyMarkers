# Private Party Markers

[English](README.md) | **简体中文**

Private Party Markers 是一个 Dalamud 插件，可在自己和手动选择的小队成员脚下绘制仅本机可见的小圆点。

- 标记只在自己的客户端中绘制。
- 不设置或修改游戏内的目标标点与场景标点。
- 不自动选择目标，不执行技能，也不上传玩家身份或位置。
- 每位选中的成员可以使用 16 种预设颜色之一。
- 队友离开小队、不再加载或无法投影到屏幕时，立即停止绘制。
- 支持简体中文、繁体中文、英语和日语。

## 安装

1. 安装并启动 XIVLauncher，确认 Dalamud 已启用。
2. 打开 **Dalamud 设置 → 测试版**。
3. 添加下面的自定义插件仓库地址：

   ```text
   https://raw.githubusercontent.com/chefiffer/dalamud-plugins/main/repo.json
   ```

4. 打开插件安装器，搜索 **Private Party Markers** 并安装。
5. 在游戏聊天栏输入 `/partydots` 打开设置窗口。

选中的成员只会以 `名字@主服务器ID` 的形式保存在插件本地配置中。分享配置文件前请自行检查。
