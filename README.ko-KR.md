# Private Party Markers

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | **한국어** | [Русский](README.ru-RU.md) | [Português (Brasil)](README.pt-BR.md) | [Español](README.es-ES.md) | [ไทย](README.th-TH.md) | [Tiếng Việt](README.vi-VN.md) | [日本語](README.ja-JP.md) | [Deutsch](README.de-DE.md) | [Français](README.fr-FR.md)

Private Party Markers는 자신과 직접 선택한 파티원 발밑에 작고 비공개인 바닥 점을 그리는 Dalamud 플러그인입니다.

- 표시는 자신의 클라이언트에만 그려집니다.
- 게임 내 대상 징표나 필드 징표를 설정하거나 변경하지 않습니다.
- 대상 선택이나 기술 사용을 자동화하지 않으며 플레이어의 신원이나 위치를 업로드하지 않습니다.
- 선택한 파티원마다 16가지 사전 설정 색상 중 하나를 사용할 수 있습니다.
- 파티원이 파티를 떠나거나, 더 이상 로드되지 않거나, 화면에 투영할 수 없으면 표시를 중단합니다.
- 중국어 간체, 중국어 번체, 영어, 일본어를 지원합니다.

## 설치

1. Dalamud가 활성화된 XIVLauncher를 설치하고 실행합니다.
2. **Dalamud Settings → Experimental**을 엽니다.
3. 다음 사용자 지정 플러그인 저장소 URL을 추가합니다.

   ```text
   https://raw.githubusercontent.com/chefiffer/dalamud-plugins/main/repo.json
   ```

4. 플러그인 설치 관리자를 열고 **Private Party Markers**를 검색한 뒤 **Install**을 선택합니다.
5. 게임 채팅에서 `/partydots`를 입력하여 설정 창을 엽니다.

선택한 파티원은 `name@home-world-ID` 형식으로 플러그인의 로컬 설정에만 저장됩니다. 설정 파일을 공유하기 전에 내용을 확인하세요.
